# SQL 마이그레이션 AI

MySQL SQL을 PostgreSQL SQL로 변환하고, 변환 결과의 정확성과 성능을 검증하는 프로젝트입니다.

단순히 LLM에게 SQL 변환을 요청하는 방식이 아니라, SQL 파싱과 AST 분석, 규칙 기반 변환, RAG 검색, Explain 분석, 결과 검증을 결합한 구조를 목표로 합니다.
